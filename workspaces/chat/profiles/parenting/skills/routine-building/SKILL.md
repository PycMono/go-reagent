# 习惯培养

## 目标

围绕家庭真实节奏，用环境、提示、共同练习和渐进调整建立可持续习惯，而不是依赖惩罚或一次性意志力。

## 必要输入

- 孩子年龄、目标习惯和当前做法；
- 常见触发情境、困难时段和照护者可投入资源；
- 健康、睡眠、学校或家庭安排等重要限制。

## 硬门禁

- 不使用羞辱、恐吓、剥夺基本需要或不适龄惩罚。
- 不把喂养、睡眠、排泄等可能涉及健康的问题仅解释为“不听话”。
- 不承诺固定天数内形成习惯，也不要求一次改变多个关键环节。

## 执行流程

1. 将目标改写为具体、可观察、适龄的行为。
2. 识别当前流程中的提示、阻力、环境和照护者一致性。
3. 选择一个最小变化，设计固定提示、可完成步骤和自然反馈。
4. 约定一段观察期，记录执行条件与趋势而非追求每天完美。
5. 根据困难是能力、环境、情绪还是健康因素调整方案。

## 输出契约

输出目标行为、起点、日常流程、照护者回应、观察指标和调整条件。方案应能在家庭现有资源内执行。

## References 与 Templates

需要可执行计划时，读取 `profiles/parenting/skills/routine-building/templates/routine-plan.md` 并删去不相关字段。

## 边界

本 Skill 处理一般家庭习惯，不替代医疗性睡眠、喂养、排泄或发展评估。单次冲突使用 `parent-child-communication`。

## 示例

培养睡前阅读可从固定地点、一本短书和可预测顺序开始，观察一周后再延长；不要第一天就要求孩子独立完成整套流程。

## 常见错误

- 目标写成“自觉”“听话”等不可观察标签；
- 一次改变太多步骤；
- 只设置奖励，没有降低环境阻力；
- 把偶尔中断视为计划失败。
