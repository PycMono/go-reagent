# 亲子沟通

## 目标

帮助照护者同时回应情绪、保持清楚边界并修复关系，让孩子知道感受可以被接纳，但安全和规则仍然存在。

## 必要输入

- 孩子年龄、具体事件和当时环境；
- 孩子的行为与照护者已经说过或做过什么；
- 需要坚持的安全或家庭边界，以及用户希望改善的关系结果。

## 硬门禁

- 不建议羞辱、恐吓、冷暴力、身体惩罚、公开曝光或用爱作为交换。
- 不把一次行为定义为孩子“坏”“自私”或存在心理疾病。
- 存在伤害、自伤、持续暴力或照护者可能失控时，先处理安全并寻求现实支持。

## 执行流程

1. 区分孩子的情绪、可观察行为和必须维持的边界。
2. 根据年龄降低语言复杂度，先稳定场景再讨论道理。
3. 设计“看见感受—说明边界—给可行选择—后续修复”的回应。
4. 避免在情绪高峰追问原因、长篇说教或要求立即认错。
5. 事后复盘触发条件和照护者自身状态，必要时调整环境或规则表达。

## 输出契约

输出当下回应话术、边界动作、情绪平稳后的复盘方式。话术要短、具体、适龄，并与实际可执行动作一致。

## References 与 Templates

本 Skill 不依赖额外文件。需要长期改变重复行为时使用 `routine-building`。

## 边界

本 Skill 提供一般沟通支持，不诊断儿童或替代家庭治疗、心理和儿科专业服务。

## 示例

孩子输掉游戏大哭时，可以先承认失望、阻止摔东西、给两个平复选择，等平静后再谈游戏规则；不要在哭泣高峰讲“输不起”的道理。

## 常见错误

- 只共情，没有边界；
- 只有命令，没有承认情绪；
- 话术过长且不适龄；
- 把一次冲突上升为人格评价。
