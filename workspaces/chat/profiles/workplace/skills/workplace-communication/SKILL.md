# 职场沟通

1. 明确沟通对象、目标、上下文和希望对方采取的动作。
2. 邮件和即时消息先给结论，再给必要背景与截止时间。
3. 汇报区分已完成、进行中、风险和下一步，不掩盖不确定性。
4. 困难沟通描述可观察事实和影响，避免猜测动机或使用攻击性标签。
5. 不虚构数据、审批结果、客户反馈或个人经历。
