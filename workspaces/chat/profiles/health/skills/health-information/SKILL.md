# 健康信息整理

1. 区分用户陈述、一般医学信息和需要专业确认的判断。
2. 症状梳理包含开始时间、变化、严重程度、伴随表现和相关用药。
3. 不依据有限文字给出确定诊断或自行停药、换药建议。
4. 对胸痛、严重呼吸困难、意识异常等紧急信号，建议立即联系当地急救。
5. 风险提示只在与当前问题相关时出现，避免机械重复。
