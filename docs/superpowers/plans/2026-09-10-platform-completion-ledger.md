## 后续核对与补齐（2026-09-10）

接续上述已存在的未提交实现，没有撤销其他改动。本次开始的全量测试实际发现两个编译缺口：`PIFactory.authorOptions` 与 `RegisterPublicationRoutes` 尚未实现。已补齐并完成服务器训练/发布装配。

本次补齐：

- 训练作者 Runtime、全套训练 HTTP、版本激活与快捷模型发布路由；复用 pi 与现有服务分层。
- 数据目录独占锁、显式停止确认的启动恢复、从数据库 HEAD 重建候选、发布准备对账与失败清理。
- 修复 checkpoint 后 diff 恒空、restore 成功后的清理失败误报、失败验证诊断丢失、执行中刷新失败、取消按钮禁用。
- 真实 MySQL 发现并修复：0009 后训练查询仍读 profile_code；SDK 固定 PRC 解析导致 UTC 期限提前八小时。
- 配置中的批准解释器真正接入原生禁网检查，校验使用 Runtime 管理器共用容量；没有扩展 SDK 网络策略或新增框架。
- 增加离线 `cmd/agent-migrate` 的 bootstrap/check/backfill/verify、严格归属映射和 Git 完整性核验。
- 按用户 `needs/img.png` 新增“左侧只读候选试聊、右侧对话训练”布局和 `/training-sessions/:id/preview`，试聊不进入训练历史、不获得写工具；管理页同步重排。

已取得证据：完整 Go 单元回归曾全通过；前端 38 项测试通过；MySQL 8.4.11 实测训练输入/输出持久化、去重、校验、发布、回滚通过；macOS Seatbelt 与 Linux Bubblewrap 脚本语法/不执行业务代码测试通过。新增预览用例验证读取当前候选且不修改训练状态/消息。浏览器完成右侧训练→左侧试聊→校验→人工发布；测试使用隔离数据库和固定作者替身。

仍需本次收尾复核：最新改动的全量/竞态回归、迁移/恢复故障覆盖、最终页面窄屏核验与独立审查。真实宿主登录、客户数据归属、生产迁移、异机备份配置及真实模型回答质量不由本地测试替代，未执行生产部署。
