# 工具调用循环检测

检测两种情况，**都要求工具名和参数相同**：

1. **相同工具 + 相同参数**重复调用：最近 16 条调用历史中，计入当前调用后达到 3 次，提醒模型，但继续执行。
2. **相同工具 + 相同参数 + 相同结果**重复出现：同一调用连续获得 5 次相同结果，下次再调用时阻止整批执行，给模型一次换方案的机会；本次 Run 第二次触发这种拦截时终止。

例如，每次只调用一次同样的工具、传同样的参数，且结果始终相同：第 3 次提醒，第 6 次拦截；紧接着仍重复调用就终止。

不同工具或不同参数，即使返回内容一样，也不会合并计数。同一调用的结果变化会重置结果计数，中间调用其他工具不会打断计数；调用完全离开历史窗口后，其状态会清除。

默认启用，可通过 `Disabled` 关闭，或用 `ExcludedTools` 排除合法轮询等工具。参数或输出正文持续变化的循环可能漏检，运行预算由 governor 兜底。
