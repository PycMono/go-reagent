# Repository Development

Use this Skill when the current request concerns the go-reagent source repository.

1. Read the relevant source and tests before changing behavior.
2. Preserve unrelated workspace changes.
3. Keep the runtime domain-neutral; business identity and behavior belong to the caller's Workspace.
4. Add or update focused tests for behavior changes.
5. Run focused verification first, then the broadest practical test suite.
